## 결선

T-Display의 윗줄 헤더 한쪽으로 모았습니다.

| e-paper 핀 | T-Display GPIO | 비고 |
|---|---|---|
| VCC | 3V | |
| GND | G | |
| SDA(MOSI) | 26 | |
| SCL(SCK) | 25 | |
| CS | 27 | |
| D/C | 33 | |
| RES | 32 | |
| BUSY | 37 | 입력 전용 핀 |

- **SPI 재매핑**: `SPI.begin(25, -1, 26, -1)` 다음 `display.init(115200, true, 50, false)`, `setRotation(0)`(400×300 가로)
- **사용 금지 핀**:
  - 온보드 LCD: 18, 19, 5, 16, 23, 4(백라이트)
  - 스트래핑: 0, 2, 12, 15. BUSY를 GPIO2에 두면 업로드할 때마다 리셋 버튼이 필요했음.
- **배터리 전압**: GPIO34(ADC, 1/2 분압). 측정할 때만 GPIO14(ADC_EN)를 HIGH로 둡니다. 클론 보드에서도 동작 확인.
- **LCD 백라이트**: 부팅 직후 GPIO4를 LOW로 두고 LCD는 초기화하지 않습니다(절전).
- **e-paper 확인**: 결선만 확인할 때는 [`test_epaper.ino`](test_epaper.ino)를 Arduino IDE로 올립니다.

| [`case/shell.stl`](case/shell.stl) | 본체(앞판 + 측벽) |

STL은 GitHub에서 바로 3D 미리보기가 됩니다.

- **외형**: 약 101 × 99 × 18.5mm
- **본체**:
  - 표시 창(바깥쪽 45° 모따기)
  - 기판 받침 턱
  - 오른쪽 벽 USB-C 구멍
  - 모서리 M2 나사 구멍
- **뒷판**:
  - 바깥면 자석 포켓
  - 안쪽 배터리 울타리, T-Display 가이드, 기판 누름 기둥
- **출력**: 본체는 앞면, 뒷판은 바깥면을 베드에 두고 서포트 없이 출력합니다.
- **치수 근거**:
  - WeAct 보드 외형도(기판 91.8×89.8, 장착홀 가장자리 2.8mm, Ø2.8)
  - 패널 사양서(외곽 91×77×1.15, 표시 영역 84.8×63.6)
  - 실측(92×89)
- `[MEASURE]` 표시가 있는 값은 캘리퍼로 실측해 고쳐야 합니다.

### 알려진 문제와 개정할 점

- **결선 변경 미반영**: 케이스는 예전 결선(아래 줄 7개 + 37번) 기준으로 듀폰 공간을 잡았습니다. 지금은 윗줄 한쪽으로 모았으니 T-Display 위치와 가이드를 다시 배치해야 합니다.
- **배터리 치수**: 설계는 603450(54×35×6.5mm) 기준입니다. 3500mAh 셀을 쓰면 `bat_w/bat_h/bat_t`와 `comp_d`를 실측값으로 바꿔야 합니다.
- **고정**:
  - 큰 배터리 무게로 앞판과 뒷판이 벌어졌습니다.
  - 배터리를 **뒷판(자석 쪽)에 양면 폼테이프로 붙여** 무게가 바로 자석에 실리게 하고, 모서리를 M2 태핑 나사나 글루건으로 고정했습니다.
  - 리튬 셀이 부풀 수 있으니 완전히 밀봉하지는 않습니다.
- **WiFi**:
  - 철문에 붙이면 보드 PCB 안테나가 철판에 가려 신호가 크게 떨어집니다(문밖 RSSI -75~-85dBm).
  - 안테나 쪽(USB-C 반대쪽 끝)을 위로 두고 철판에서 조금이라도 띄우는 구조가 좋습니다.
  - 다음 개정에서 스페이서를 넣는 것을 검토 중입니다.
- **전원 스위치**: T-Display 전원 스위치가 케이스 안쪽을 향해 밖에서 조작할 수 없습니다. ON으로 고정해 씁니다.
